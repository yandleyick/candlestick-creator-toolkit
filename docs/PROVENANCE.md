# Provenance and scope

## Inventory

The catalog was assembled on 2026-11-11 from the saved FMHY toolkit catalog and current local file presence. The FMHY selection was recorded on 2026-10-20: 27 primary tools, two runtime packages, 14 pre-existing tools, and 28 saved web resources. The older source index contained 5,360 links, which were not individually evaluated. This repository carries the selected tools and named skip decisions rather than representing all indexed links as approved tools.

The original toolkit audit recorded 29 package files, 27 publisher-checksum matches, 25 checks marked passed, and two expected help/usage responses. It did not validate every graphical workflow. Historical recorded hashes are not fresh executable signatures or current malware checks. URLs and software releases can change.

## Boundaries

The repository contains catalog metadata, public publisher links, authored workflow code, small calibration images, and synthetic examples. It does not contain private recordings, copyrighted lyric collections, model weights, paid application installers, credentials, browser data, signed download URLs, or project-specific personal notes. External services and plugins mentioned in previous projects are not bundled executable software.

The accompanying verification report states what was actually exercised during packaging. Package syntax checks, synthetic fixtures, and source-presence checks are distinct from real-footage detection accuracy, GUI import/playback, and creative approval.
