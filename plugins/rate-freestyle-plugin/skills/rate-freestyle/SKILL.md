# Rate freestyle

Judge the material the user supplies or identifies with a consistent, transparent rubric. A great freestyle should develop connected ideas: later lines should build on earlier ones through meaningful transitions, callbacks, setups, payoffs, or a progressing story. Reward this explicitly rather than treating isolated punchlines or dense rhymes as sufficient.

## Establish the comparison

1. Recover any requested prior rubric or context from accessible sources. Do not claim to remember or import an unavailable conversation or skill. Current user instructions take precedence over defaults.
2. Resolve the performers, recordings, number of selections, duration, and requested categories. Use context to resolve routine choices. Clarify a materially ambiguous term such as "availability" before scoring it; do not silently rename it accessibility, relatability, or freestyle ability.
3. Make a source inventory before claiming exhaustive coverage. Record each entry's URL, title, duration, transcript status, timestamp status, speaker attribution, and any exclusion. Distinguish a site's named collection from an inferred genre or duration threshold.
4. Attribute performers using explicit source labels, reliable credits, self-identification in speech, or user-provided speaker labels. Do not identify or verify a person by comparing voices to a reference recording. When attribution is unclear, ask the user to label entries or timestamped turns. A reference voice clip alone does not resolve identity.
5. Distinguish transcript-only lyrical analysis from an audio-supported performance review. Score delivery, flow, breath control, timing, and audible responsiveness only when the relevant audio can actually be inspected.

## Obtain usable evidence

- Retrieve the requested material through available connected tools. Preserve source provenance and the original timestamp basis. Do not evade access restrictions.
- Use accurate captions, timed transcripts, or inspected audio to establish clip boundaries. Untimed text supports lyrical analysis but does not establish 20–30-second windows. Never estimate precise timestamps from word counts and label them verified.
- Mark uncertain words and automated transcription errors. Do not invent sophisticated wordplay to repair garbled text. Read surrounding context before interpreting an ambiguous line.
- Review every accessible eligible entry before claiming the "best across all entries." Report unreviewed or unavailable entries and the scope they exclude.
- Analyze copyrighted material without reproducing full lyrics or compiling a substitute lyric anthology. Deliver source links, verified start/end times, short compliant quotations when useful, and original critical analysis. Apply quotation limits cumulatively.

## Select excerpts

Use the user's requested length. For a 20–30-second request, each selected interval must be continuous and between 20.0 and 30.0 seconds inclusive. Prefer complete phrases and meaningful setups/payoffs. Inspect surrounding material to avoid awarding a payoff whose setup has been cut away.

Build a broad candidate pool, score candidates, then select. Avoid overlapping selections from the same recording and repeated versions of the same bars unless the user explicitly wants overlapping highlights. Do not make one strong passage appear several times under shifted boundaries.

Unless the user asks for quotas, choose the strongest verified excerpts across the full eligible corpus. When multiple named sessions must be represented, include each session without inventing an equal quota. Show the distribution by recording and disclose different corpus sizes or editing conditions. Distinguish "best-of highlights" from sustained freestyle ability.

Do not manufacture enough entries to meet a target. If evidence supports fewer verified clips than requested, return the verified subset, the shortfall, and the precise missing input.

## Score lyrical strength

Read [the rubric](references/rubric.md). Grade each category from 0 to 10, normally in half-point increments, and attach an evidence-specific reason. Use the same anchors for both performers. Scores are critical judgments, not objective measurements.

Default weights for a general lyrical comparison are complexity 30%, depth 30%, and connected development 40%. If accessibility is requested, use complexity 25%, depth 25%, connected development 35%, and accessibility 15%, unless the user specifies another weighting. Keep an unresolved custom category unscored. State weights before the final ranking and do not tune them after seeing who wins.

Compute the total out of 100 as the sum of each 0–10 category score multiplied by its percentage weight divided by 10. Keep source confidence separate from artistic merit. Use N/A for unavailable evidence, never zero. Do not publish a full weighted total when a required category is missing without explicitly defining and labeling a provisional alternative.

Connectedness can support an interpretation of improvisation, but written lyrics can also be tightly connected. Report separate observational support for improvisation: unanticipated prompts, environmental responses, live corrections that become meaningful lines, and specific callbacks to earlier spontaneous events. Avoid percentages or certainty about whether material was unwritten unless reliable evidence establishes it. Flow, length, and polish alone are not proof.

## Independent review and head-to-head rounds

Use a second agent only when the user or governing instructions authorize delegation. When the user requests a "twin," create an independent reviewer with the same rubric and source evidence. Have both reviewers score before seeing one another's scores where practical. Do not call scores independently reviewed if the second reviewer only gathered sources.

Reviewers should identify disagreement, transcription uncertainty, context dependence, and selection bias. Reconcile large category disagreements against the evidence; preserve the initial scores and rationale when practical rather than simply averaging away disagreement.

For an equal-size mock contest, default to rank-matched pairings: best against best, second against second, and so on. State that this evaluates comparable highlight ranks, not a live battle or overall career superiority. If the user prefers random or thematic pairings, establish the method before deciding winners.

For every round provide both source/timestamp links, the category scores, each excerpt's main strength and limitation, the decisive comparison, and a verdict. Explain the connection of ideas, not merely a list of reference names. Treat a total gap of 3 points or less out of 100 as a draw by default because of grading precision, unless the user asks for forced winners. If one is chosen despite a close score, label it a narrow subjective edge.

Report wins, losses, draws, category averages, reviewer disagreement, source limitations, and the extent to which the result depends on the stated weights. Do not rank a performer's entire ability from a small or selectively edited sample.

## Deliverable and verification

For large comparisons, supply a score table and detailed round notes in a durable artifact the user can open. Each clip row should contain: ID, performer attribution and basis, recording/session, URL, start, end, duration, concise description, category scores and reasons, weighted total, transcript confidence, timing confidence, connection to surrounding context, and reviewer status.

Before delivery check the actual row count, unique source intervals, duration bounds, non-overlap, category completeness, weight sum, score arithmetic, round count, and win/draw totals. Use data validation where it helps. Never claim collection, listening, scoring, independent review, account installation, or completion that has not happened.

If blocked, preserve completed research and the rubric. Ask only for the missing material that will unlock the next step, such as timed captions or a user-labeled speaker map. Continue independent work that does not depend on the missing input.
